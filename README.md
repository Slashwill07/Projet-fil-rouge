# Projet-fil-rouge
membres de l'équipe : Alec Germain et William Comsel

Fonctionnalité supplémentaire : Les utilisateurs vont avoir un avatar qui leur est attribué. Cela implique : 
- Qu'ils vont devoir choisir leur avatar parmi une sélection lors de l'inscription dans le site.
- Que l'avatar des amis de l'utilisateur est affiché à côté du nom des amis partout dans le site.
- Que lorsqu'un utilisateur devient inactif, son avatar se met à dormir
